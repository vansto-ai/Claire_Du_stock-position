# 指定标的持仓变动可视化

这是一个基于 Streamlit 的本地证券流水分析工具，用于根据指定账户和证券简称，计算每日持仓并显示折线图。

## 功能

- 上传 CSV / XLSX / XLS 流水文件
- 支持按账户名称筛选
- 支持按证券公司名称可选筛选
- 支持按证券简称筛选指定标的
- 按日期累计计算每日持仓
- 展示摘要指标与持仓明细表
- 处理缺失字段、非法日期、非法数量和负持仓警告

## 运行方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 数据字段要求

必须包含以下字段：

- 账户名称
- 证券公司名称
- 交易日期
- 证券简称
- 买卖标志
- 成交数量

其中：

- 证券公司名称允许为空
- 买卖标志建议填写 B / S，或中文 “买 / 卖”
- 成交数量必须能转换为数字
